\# Структура файлов данных



\## Описание

Папка содержит файлы для выполнения лабораторной работы по обработке данных о рейтингах.



\## Файлы



\### ratings.csv

Исходный файл с данными о рейтингах фильмов.



\- \*\*Формат:\*\* CSV

\- \*\*Структура:\*\*

&#x20; - `userId` — идентификатор пользователя

&#x20; - `movieId` — идентификатор фильма

&#x20; - `rating` — оценка

&#x20; - `timestamp` — временная метка


\### ratings\_count.txt

Файл с результатами анализа данных.



\- \*\*Формат:\*\* Текстовый файл

\- \*\*Содержимое:\*\* Две строки с информацией о минимальном и максимальном идентификаторах пользователей

\- \*\*Формат строк:\*\* `userId количество\_записей`





\### sqlite.txt

Информационный файл о настройках SQLite.



\- \*\*Содержимое:\*\* 

&#x20; - Версия установленной SQLite

&#x20; - Список доступных режимов вывода данных

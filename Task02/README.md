\# Task02: ETL-процесс для базы данных SQLite



\## Требования к окружению

Для корректной работы скрипта `db\_init.bat` на компьютере должны быть установлены:

1\. \*\*Python v.3.x\*\* (проверка: `python --version`)

2\. \*\*SQLite3\*\* (проверка: `sqlite3 --version`)



\## Как использовать

1\. Откройте терминал в папке `Task02`.

2\. Выполните команду: `bash db\_init.bat` (или `./db\_init.bat` в PowerShell).



После выполнения будет создана заполненная база данных `db\_init.db` с таблицами: `movies`, `ratings`, `tags`, `users`.
